# 字段口径与取数对照表

raw.json 每个字段的**来源接口、口径、注意事项**。口径不一致会让分数失去跨期可比性，务必对齐。

## 字段对照

| raw.json 字段 | 含义 | 单位 | 来源 | 口径 / 注意 |
|---|---|---|---|---|
| `code` | 标的代码 | — | — | `sh`/`sz`/`bj` + 6 位；港股 `hk`+5 位；美股 `us`+代码 |
| `name` | 简称 | — | — | 用于图表标签，≤4 字显示效果最好 |
| `scode` | 纯数字代码 | — | — | 报告里展示用 |
| `ind` | 行业/板块标签 | — | — | 用于组合行业集中度分析，写业务实质而非申万分类 |
| `px` | 最新收盘价 | 元 | westock `asfund.ClosePrice` 或 `kline` | 必须与 `ff1`（当日资金）同一天 |
| `d1` `d5` `d20` | 近 1/5/20 交易日涨跌幅 | % | `kline` 自行计算 | 用**收盘价**口径：`cur/close[n]-1`，n 取 1/5/20 |
| `y1` | 近 1 年累计涨跌幅 | % | `kline`（limit≥245） | 用于风格分化分析 |
| `pe` | 滚动市盈率 PE-TTM | 倍 | neodata「统一估值查询」 | 逐只查；不要用财务块里的"动态市盈率"替代，两者不等 |
| `pepct` | PE 五年历史分位 | % | neodata 同上 | **5 年窗口**，非 10 年；越低越便宜 |
| `pb` `pbpct` | 市净率 / 五年分位 | 倍 / % | neodata 同上 | 与 PE 分位 55 开配比使用 |
| `dy` | 股息率 | % | `dividend` 近 12 个月**已实施**方案 ÷ `px` | 不含已公告未实施；有中期+年度的要合计（如茅台 10派280.242 + 10派239.570） |
| `roe` | 加权净资产收益率 | % | neodata「综合财务指标」→ 盈利能力 | 年报口径。注：港股上市年份的加权 ROE 会高于基本 ROE（权益中途增大），属正常 |
| `npm` `gpm` | 销售净利率 / 毛利率 | % | 同上 | 年报口径 |
| `np_yoy` | 归母净利润同比 | % | 同上 → 成长性 | 评分里是质量维度权重最大的一项（25%） |
| `rev_yoy` | 营业收入同比 | % | 同上 | 只作展示，不进评分（营收增速噪音大于利润增速） |
| `debt` | 资产负债率 | % | 同上 → 资产负债结构 | 反向计分 |
| `cr` `qr` | 流动比率 / 速动比率 | — | 同上 | `cr < 1` 应在报告里标红 |
| `fcf` | 自由现金流量 | 亿元 | 同上 → 现金流状况 | **可为负**（比亚迪 −1206 亿）；缺失填 0 |
| `ff20` `ff5` `ff1` | 20 日 / 5 日 / 当日主力净流入 | 亿元 | westock `asfund` 的 `MainNetFlow20D` / `MainNetFlow5D` / `MainNetFlow` | 原值为元，**÷1e8 转亿元**；流出为负 |
| `mcap` | 总市值 | 亿元 | 推算：`归母净利润 ÷ 每股收益 × px` | **资金维度必填**，用于归一化。接口无市值字段时用此推算 |
| `ma20` `ma60` `ma250` | 20/60/250 日均线 | 元 | westock `technical --group ma` | 判断趋势破坏程度 |
| `rsi6` | RSI(6) | 0–100 | `technical --group rsi` | 15 以下视为极度超卖 |
| `kdj_j` | KDJ 的 J 值 | — | `technical --group kdj` | 可为负（实测立讯 −8.31），极端超卖 |
| `macd` | MACD 柱状值 (DIF−DEA) | 绝对值 | `technical --group macd` | 评分里按 `macd/px` 归一，否则高价股与低价股不可比 |
| `vol` | 年化波动率 | % | `kline` 日收益率标准差 × √243 | 用于组合波动归因 |

## 顶层字段

| 字段 | 说明 |
|---|---|
| `index_name` / `index_20d` | 指数基准名与其近 20 日涨跌幅（默认沪深300），用于计算超额收益 |
| `weights` | 四维权重，默认 `{qual:.45, flow:.20, val:.20, tech:.15}` |
| `thresholds` | 判断阈值，默认 `{keep:70, watch:52}`；≥keep→保留，≥watch→观察，否则减仓 |

## 解析三类返回格式的要点

### 1. westock `kline`（管道分隔表）

```
| symbol | date | open | last | high | low | volume | amount | exchange |
```
`strip('|').split('|')` 后 9 个元素，**索引 3 是收盘价**。写成索引 4 会取到 `high`，导致所有区间涨跌幅系统性偏乐观。

### 2. westock `asfund`（宽表，一行一只）

关键列：`ClosePrice`、`MainNetFlow`、`MainNetFlow5D`、`MainNetFlow10D`、`MainNetFlow20D`。单位是**元**。
`quote` 子命令在本渠道不可用，收盘价从这里取。

### 3. neodata「综合财务指标」（多级 Markdown）

结构：
```
## 股票名（标的代码：600519.SH）
### 1、资产负债结构
| 表头... |
| :---: | ... |      ← 分隔行，必须剔除
| 数据... |
### 2、现金流状况
...
```
解析要点：
- 按 `\n## ` 切分股票，按 `### \d、` 切分小节
- 每小节剔除纯分隔行（正则 `^\|[\s:|-]+\|$`），再取最后一行作数据
- **按表头名索引取值**，不要按位置——不同股票返回的列可能不完全一致
- 一次查询最多返回 4 只股票，第 5 只需单独补查
