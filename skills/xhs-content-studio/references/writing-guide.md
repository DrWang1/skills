# 小红书文案写法参考

## 标题（≤ 20 字）

优先使用可复用的骨架，套入素材里的具体对象：

- 情绪冲突：`被___惊到了！` / `别再___了` / `折腾___后我麻了`
- 数字清单：`3 个___，第 2 个我一直在用` / `花了 X 天，我总结出___`
- 身份代入：`打工人必看：___` / `新手做___，先看这篇`
- 反差结果：`本以为___，结果___`

标题里放**一个具体对象 + 一个情绪词**，避免空泛形容词堆砌。

## 正文结构

```
钩子（前 2 行必须抓人：痛点/反差/结果）
↓
展开（3–5 个短段，每段 1–3 句，多用换行）
↓
干货/清单（能落地的步骤、对比、避坑）
↓
互动引导（提问 / 站队 / 求同款）
```

- 多用短句和换行，手机一屏内读完一段。
- 口语化，少用书面连接词。
- 可适度用 emoji 分隔，但不要每行都加。
- 结尾放 1–2 个引导评论的问题。

## 标签（3–8 个）

- 结构：`1 个大词（赛道）+ 2–3 个精准词（场景/人群）+ 1–2 个长尾词`
- 例：`#AI工具 #效率提升 #打工人 #职场干货 #自媒体运营`
- 避免无关大流量词，避免堆砌 10+ 标签。

## 图文/封面（1080 宽）

- 首图 = 标题的视觉化，信息密度高、字号大、对比强。
- 图内文字建议：主标题 ≤ 12 字，副标题 ≤ 20 字。
- 系列图每页一个要点，统一字体与配色。
- 用 `render_cover.py` 渲染时，Markdown 一级标题作为页内主标题。

## 合规与避坑

- 不写绝对化用语（"最""第一""100% 有效"等）。
- 不虚构数据、疗效、收益。
- 医疗/金融/教育等敏感领域需谨慎，避免承诺性表述。
- 引用他人内容注明来源，不使用未授权图片。
